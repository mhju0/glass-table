## Findings and decisions
Operational facts still relied on:
- GitHub `mhju0/glass-table` is public with no LICENSE (all rights reserved, D18). GitHub Pages serves `docs/` from `main`: `https://mhju0.github.io/glass-table/privacy-policy.html` and `support.html` (support page added by PR 10, merged as `8e808ca`, 2026-10-02). Repo homepage points at the policy.
- Bundle ID `com.michaelju.glasstable`. Device installs are Release builds (debug flop pricing ~2.5 s vs ~35 ms release). Free personal-team provisioning (7-day expiry) was used before enrolment.
- Zero runtime networking, analytics or accounts; privacy label "Data Not Collected". Store state is one `Application Support/progression.json` (atomic writes, `.fresh/.loaded/.unreadable`, `progression.recovery-<UUID>.json` copies before reset/import; D43).
- `GT_DEMO_*` DEBUG launch hooks are the screenshot sweep's way into screens; `GT_DEMO_SEED=1` builds demo state through real types. Do not remove without replacing the sweep.
- Test environment lessons: `name=iPhone 17` resolves to the iOS 27 beta, so use the iOS 26.5 device id. A stale installed UI-test runner can run after a rebuild; fix with `xcrun simctl uninstall <device> com.michaelju.glasstable.GlassTableUITests.xctrunner`. App language and other preferences persist in simulator UserDefaults across tests (uninstall or clear first). Xcode 27's CLI will not download iOS 18 runtimes. CI's Xcode 26.x type checker times out on long SwiftUI expressions/`#expect` (split them). `-only-testing:.../UXAuditCrawl` alone ran zero tests; name the methods. Leftover `outs-progress.json` in a sim container broke a fresh-store test.
- Known sweep non-determinism: `teach-showdown-b3`/`-b5` differ 0.05-0.24 % run to run (card fade-in). Do not chase.
