## What it was
`milestone-1.md` scoped the first shippable app: a free, Korean-first Math Drills app built on a correctness-proven equity core, chosen as the lowest-risk path through Swift, the decide-grade loop and the Korean rating track before any betting table. The six plans were step-by-step TDD task lists for each M1 sub-project and the first revamp sub-project. Design specs for each live in `docs/specs/` and decisions in `docs/decisions.md` (D01-D23, D26); this record keeps the plan-only facts.

## Findings and decisions
- M1 scope in: decide-reveal-grade loop with estimation bands 정확/근접/빗나감; five drills (outs + rule of 2/4, pot odds, call/fold, MDF, blocker counting); from-scratch equity core with golden fixtures, oracle cross-check, property and determinism tests; Korean-first UI; local progress; benchmarks computed on the fly, never stored. Out: table, bots, ranges, 13x13 grid, Range Read, backend/IAP/ads.
- M1 success criteria: math provably right (hard gate); reveal under 100 ms after commit; App Store acceptance with KR-12/KR-15 self-rating (or GRAC direct review exercised); testers reopen voluntarily.
- Engine plan (11 tasks): Swift 5.9+, SwiftPM/XCTest, no third-party Swift deps. Card notation `23456789TJQKA` x `cdhs`, ranks 2-14, suits c=0 d=1 h=2 s=3. Equity = (wins + ties/2) / total. Tolerances: exact enumeration 1e-9, Monte Carlo/oracle +/-0.004. Evaluator deliberately naive best-of-21, marked `ponytail:` (D06); perfect hash deferred. OMPEval second oracle deferred in the plan's self-review (eval7 + golden vectors deemed sufficient; D05). `tools/gen_fixtures.py` is dev-only; verify the installed eval7 API at generation time.
- App spine plan (9 tasks): three layers Engine <- `GlassTableDrills` <- XcodeGen SwiftUI app, iOS 17, `@Observable`. Outs drill: seeded generation from `(baseSeed, index)` via `SplitMix64`, quality filter 2 <= outs <= 15, bands exact / within 2 / else. Toss-inspired design tokens (green `#157A47`, CTA `#0FA968`, green content zone + white sheet radius 24), Pretendard 400/600/700 bundled (OFL). Every source file carries `// Copyright (c) 2026 Michael Ju (github.com/mhju0)`.
- Four-drills plan (9 tasks): generic `DrillSession<Spot, Answer, Reveal>`; bet sizes only 33/50/75/100/150 % pot, integer bb; engine convention `requiredEquity(toCall: bet, pot: pot + bet)` because `pot` includes villain's bet; seed index mixed with `0x9E37_79B9_7F4A_7C15`; per-drill progress files via `ProgressStore.standard(drill:)`.
- Polish plan (6 steps, all checked): `docs/glossary.md` and bilingual home captions, stats screen, script-rendered icon (`tools/make-appicon.swift`), in-app 용어집, then a card-free table-disc + % icon. Engine diff stayed empty.
- Submission plan (11 tasks): bundle ID normalized to `com.michaelju.glasstable`; version 1.0 build 1; app name "Glass Table" on both storefronts, Korean primary; free worldwide, no IAP/ads/accounts; Simulated Gambling answered Infrequent/Mild, and a KR-19 result must stop submission, never silently submit. Task 6 made the repo public and enabled GitHub Pages from `main:/docs` to serve `privacy-policy.html` (still the hosting setup). Tasks 7-11 (enrolment, signing/upload, ASC form, TestFlight hardware checklist, submit) were external to Michael.
- Owner decision 2026-07-23 (`7daef48`): paused after Task 6 for personal dogfooding. When resumed, go only as far as a TestFlight upload; do not submit for review without an explicit go.
- R1 sub-project 1 plan (5 tasks): one atomic `Codable` `ProgressionStore` replacing five per-drill files; no SwiftData/UIKit/SwiftUI in `GlassTableDrills`; `save` throws; `load()` distinguishes no file from corrupt file and never silently returns empty; legacy files fold in once; record shapes only, logic in sub-project 2. Spec: `docs/specs/2026-08-03-r1-progression-shell-design.md` §8.
- Staleness noted later: submission Task 10's checklist still names the table-disc icon, replaced 2026-07-24 by the range-grid heatmap (`055eeb7`, `a32b03f`; D19). Checkboxes in five plans were never ticked even where the work shipped; only the polish plan is marked done.
