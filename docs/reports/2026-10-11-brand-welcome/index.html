What the current app does

The app opens at “Getting started” / “시작 안내.” Its headline is “Try one simple hand” / “카드 한 번만 비교해 볼까요.” It introduces the exercise, but never gives the app title a dedicated welcome.

Preserve: warm tone, untimed learning, help availability, experienced-user bypass, bottom action and native typography.

Change: separate app identity from instruction. The new intro uses green; the guide uses a different background and an explicit guide heading. The existing preamble is replaced, not duplicated.

The before screenshot is native. Every after screen below is an HTML proposal.

First guide screen: The next screen immediately teaches a pair. Replace the current text-only guide preamble, so this adds brand recognition without adding another explanation screen.

The decisions behind the proposals

BackgroundWelcome: native table green #153D33 in both modes, matching the fixed poker-table object. The prototype also lets you compare optional deeper #102A23 felt. Guide: existing #EBE6DB paper or #17191C charcoal. Preserve the rest of the app’s palette; the green welcome is a bounded brand surface.
Meaning beyond color“Glass Table” becomes “Getting started” / “시작 안내.” A new task and example appear. Color supports this change; it does not carry the meaning alone.
Bottom actionsStart / 시작하기 stays in the same bottom action area as the guide’s next step. Amber keeps its existing role: light amber on green uses the table’s existing accent, while the light guide uses its familiar deeper amber. No centered button that jumps to the bottom on the next screen.
Guide contentStart leads to a concrete pair example, then the existing comparison activity. No knowledge quiz returns to the front of this sequence; no extra “ready?” page is added. The approved five comparisons remain the intended native course scope.
Experienced usersKeep Skip guide in the guide header. The intro stays one primary action. Skipping should keep its existing behavior and never grant completion credit.
When it appearsProposed first-run welcome, not a recurring gate on every app launch. Returning users resume their activity. Guide replay starts at the guide; the brand intro does not become an extra replay step.
MotionA native forward transition into the guide, reversible with visible Back. No timer, loop, delayed button or dramatic celebration. Reduced Motion uses a quiet/static equivalent. HTML motion only approximates native behavior.
English / KoreanBrand name stays “Glass Table.” Pair short semantic groups to equal normal line counts. Korean wraps at words; no letter splitting, font shrinking or clipping to force parity. Large text may reflow naturally.
Saved stateFuture implementation must preserve question seeds, existing saved guide steps, skip/resume, progress and recovery. The welcome must not reset or re-assess existing learners.

How this fits Apple’s guidance

Apple permits branded welcome/onboarding content, and recommends brief onboarding that teaches through the experience. That supports a single brand screen followed by cards rather than more introductory text. Apple: Branding · Apple: Onboarding

The tappable welcome is an app screen. The OS launch screen should match the first appearance and disappear when ready; it should not create a second timed intro. Apple: Launching

Keep color roles and contrast consistent across the transition. A labeled guide header and task change help make the new stage clear alongside its background. Apple: Color

Checks and implementation limits

24 clickable-flow combinations passed: three options × English/Korean × light/dark × normal/165% text. Start, guide, explanation, Back and Skip transitions worked; primary controls were reachable by scrolling without horizontal overflow. Normal guide line groups match in every language/theme pair: heading 2/2, explanation 2/2, note 1/1. Primary button geometry stays identical across the 24 normal welcome/guide frames.
