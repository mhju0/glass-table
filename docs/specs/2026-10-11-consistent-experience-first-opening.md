# Consistent experience-first opening — build 20

Approved October 10–11, 2026. Implementation and verification record in progress.

## Accepted scope

Experience-first welcome replaces the automatic familiarity check. Teach before the first choice, offer a neutral demonstration, explain each result, then show a factual two-example checkpoint. Invite the remaining three hand categories, an optional starting preference, or a comfortable stop. Experienced learners can bypass. The five-category finish is separate from exposure and dismissal.

Preserve Pretendard, adaptive warm surfaces, amber action roles, equal answer alternatives, shared native minimum touch targets and bottom task actions. Preserve graded chart/model meanings, chip-based Free Play, help-neutral public progress, compact settings, canonical Korean terms, seeded grades and offline operation. Existing implementation is retained where the approved whole-app report identifies strengths, rather than copying HTML geometry.

## Persistence contract

Legacy firstLessonCompleted true remains historical handled status because earlier versions also set it on skip. Do not infer five categories from that legacy flag. Add optional opening dismissal and bounded pending-guide evidence through backward-compatible decoding, preserving schema version, historical answers and recovery bytes. A snapshot holds the seed, semantic step and committed response or demonstration by comparison. Stop saves dismissal plus snapshot together; Learn can resume that same evidence. Replay is independent. Only the full five-category final action sets the completion marker and clears pending guide. Mutations must succeed before navigation; stale callbacks must fail safely.

## Evidence limits

Native layout and automated interaction evidence cannot establish novice understanding, retention, physical VoiceOver quality or thumb comfort. iOS 17 runtime and actual bilingual beginner sessions remain separate validation targets. No App Store release is implied.
